# Test Plan – QA Automation + API Testing Demo

## 1. Scope

This project tests:

- UI flows for the SauceDemo web application:
  - Login
  - View products
  - Add to cart
  - Logout
- API endpoints for ReqRes:
  - List users
  - Create user
  - Error handling

## 2. Objectives

- Practice designing manual test cases.
- Implement automated UI tests with Selenium + pytest.
- Implement automated API tests with Python `requests` + pytest.
- Report defects with clear steps, expected vs actual results, and evidence.

## 3. Test Types

- Functional UI testing.
- API testing.
- Basic negative testing (invalid data, error codes).

## 4. Test Environment

- OS: Windows 10/11  
- Browser: Google Chrome (latest)  
- Tools:  
  - Python + venv  
  - Selenium WebDriver  
  - pytest  
  - requests
